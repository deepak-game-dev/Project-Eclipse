# Project Eclipse

A sci-fi research facility escape gameplay project focused on gameplay architecture, enemy AI, combat, and interactive systems using C++.

## Overview

Project Eclipse is a Phase 3 project in my AAA Gameplay Engineer learning roadmap. The scenario centers on escaping a sci-fi research facility while integrating multiple gameplay systems into a cohesive experience.

## Core Gameplay Scenario

Explore the facility, interact with objects, respond to enemy detection, engage in combat, and progress toward the escape objective.

## Planned and Studied Systems

- Gameplay Architecture
- Enemy AI
- Finite State Machines (FSM)
- AI Perception
- Combat System
- Health System
- Interaction System
- Events
- Timers and Cooldowns
- Object Spawning

## Technologies

- C++
- Visual Studio

## Engineering Focus

The project focuses on connecting gameplay architecture with AI behavior, combat mechanics, event-driven interactions, and mission progression.
